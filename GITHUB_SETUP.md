# GitHub Setup Instructions

## Method 1: Using GitHub Web Interface

1. Go to https://github.com/new
2. Repository name: `smart-appointment-booking`
3. Description: `Smart Appointment Booking System with JSP, Servlets, MySQL and modern UI`
4. Set to Public
5. Click "Create repository"

## Method 2: Using Git Commands

After creating repository on GitHub:

```bash
git remote add origin https://github.com/YOUR_USERNAME/smart-appointment-booking.git
git branch -M main
git push -u origin main
```
